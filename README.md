# WASD & Performance Tweaker for GTA

This little helper decreases your keyboard & mouse delay + gives you a FPS boost!

### Build Instructions:

- run the build.bat

### Usage:

- run the wasd+performance_runtime_tweaker_x64.exe
- wait for the tweaks are finished window
- enjoy crispy clean wasd movement and more fps ingame!
